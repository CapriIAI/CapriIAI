# Oi, eu sou a CapriIAI 👋

Estou tirando do papel a **Capri**: uma assistente local para ajudar a cuidar do computador — organização, monitoramento e ferramentas úteis, sem complicar.

A ideia é começar com uma base enxuta em **Rust** e crescer por partes. Quero que seja prática, transparente sobre o que faz e que peça confirmação antes de mudanças importantes.

### No momento

- Desenhando a arquitetura e escolhendo o primeiro conjunto de funções
- Priorizando execução local, desempenho e ferramentas gratuitas quando possível
- Compartilhando o progresso por aqui conforme o projeto sair do papel

Ainda é começo de jornada. Se você também curte software local, Rust ou automação, fica à vontade para acompanhar.
